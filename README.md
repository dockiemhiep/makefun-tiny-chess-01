A deterministic 4 KB Python chess engine with legal move generation,
tapered evaluation, iterative alpha-beta/PVS, quiescence, a transposition
table, null-move pruning, LMR, and complexity-aware fixed node budgets.

Run with Python 3.13 under the make.fun tiny-chess-01 environment:

```sh
python3 -P -s main.py
```
